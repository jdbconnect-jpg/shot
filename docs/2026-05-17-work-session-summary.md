# 2026-05-17 작업 세션 정리

## 1. 영상 주제와 콘텐츠 방향

- 기존 ETF 쇼츠 스크립트가 약하다는 피드백을 받고, 단순 정보 나열보다 클릭 가능한 훅과 투자자 관점의 선택 기준을 강화했다.
- `JEPI/JEPQ vs SCHD` 영상은 “월급이 필요한가, 성장인가” 프레임으로 재구성했다.
- 이후 국내 상장 ETF 인기 순위를 소재로 `국장 ETF TOP 5`, `TOP 3` 방향의 숏폼을 제작했다.
- 국장 ETF 순위는 시가총액 기준 데이터를 바탕으로 잡았고, 특정 ETF 매수 추천이 아니라 시장 온도계와 포트폴리오 비중 관점으로 설명했다.

## 2. 화면 레이아웃

- 사용자가 제공한 YouTube Shorts 참고 영상의 화면 구성을 분석해 다음 구조로 맞췄다.
- 상단: 검정 배경의 큰 훅 문구
- 강조: 노란색 키워드, 큰 숫자, 짧은 질문형 문구
- 중앙: 장면별 핵심 이미지 또는 팬더 남자 해설자
- 하단: 흰색 자막 박스
- 모바일 가독성을 위해 긴 문장보다 1~2초 안에 읽히는 짧은 카피를 우선했다.

## 3. 이미지 생성과 캐릭터 톤

- 이미지 생성 API는 OpenAI `gpt-image-2` 계열로 확인했다.
- 사용자는 “팬더가 칠판에 설명하는 느낌”보다 “남자 스크립트와 어울리는 그림을 설명하는 팬더 남자 느낌”을 원했다.
- 따라서 팬더 캐릭터는 정장, 포인터, 금융 차트, 뉴스룸 조명, 신뢰감 있는 해설자 느낌으로 조정했다.
- 썸네일은 AI 생성 배경 위에 한글 텍스트를 로컬 합성했다. 이미지 모델이 한글 텍스트를 틀릴 수 있기 때문이다.

## 4. 썸네일 작업

- 최종 썸네일 방향은 고조회 쇼츠에서 자주 보이는 구조를 참고했다.
- 적용 요소:
  - 큰 숫자: `ETF TOP 3`
  - 강한 대비: 노랑/빨강/검정/흰색
  - 짧은 궁금증: `1위는 의외?`
  - 행동 유도: `따라 사기 전에 이 순서부터 보세요`
  - 얼굴형 캐릭터: 팬더 남자 해설자
- 사용자의 피드백에 따라 텍스트 굵기를 두 차례 강화했다.
- 최종 썸네일 파일:
  - `media_agent/data_shorts/thumbnails/scr_20260517_kr_etf_top5_high_ctr_thumbnail_top3_extra_bold.jpg`
