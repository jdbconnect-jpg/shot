# 다음 개선 과제

## 1. Remotion 템플릿 안정화

- 참고 쇼츠형 레이아웃을 Remotion 컴포넌트로 완전히 이전한다.
- Pillow+FFmpeg는 fallback으로만 남긴다.
- 렌더 멈춤 원인을 분리해서 타임아웃, 오디오, public asset 경로 문제를 확인한다.

## 2. OpenAI 스크립트 생성 고정화

- OpenAI 기반 스크립트 생성 단계를 CLI 또는 Python 모듈로 명시화한다.
- 입력:
  - 주제
  - 데이터 출처
  - 톤
  - 목표 길이
  - 금지 표현
- 출력:
  - script JSON
  - scene JSON
  - upload metadata

## 3. 썸네일 생성기 모듈화

- 현재는 수동 합성에 가깝다.
- 다음 요소를 입력값으로 받는 스크립트로 분리한다.
  - 메인 문구
  - 숫자
  - 강조 문구
  - 하단 CTA
  - 배경 이미지
  - 저장 경로

## 4. 데이터 출처 자동화

- 네이버 금융/KRX 등 ETF 순위 데이터를 안정적으로 수집한다.
- 조회 시점, 기준 컬럼, 순위 변동 가능성을 메타데이터에 기록한다.

## 5. 업로드 전 검수 자동화

- 영상 길이, 해상도, fps
- 자막 겹침 여부
- 썸네일 텍스트 가독성
- 설명란 투자 유의 문구 포함 여부
- YouTube title length
